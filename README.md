## Publish free
Fastest option: Netlify Drop
1. Open https://app.netlify.com/drop
2. Drag the entire `Sai_Raghava_Nallamala_ServiceNow_Portfolio` folder onto the page.
3. Netlify publishes it and provides a `netlify.app` URL.
4. If needed, use the project's Customize option to set a cleaner project/site name.

The site is plain HTML/CSS/JS, so no build command is required.

## Update later
Replace or edit the files in this folder and drag the updated folder to the same Netlify project's deploy area.
